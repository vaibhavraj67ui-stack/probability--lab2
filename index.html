📐 Key formulas

Basic probabilityP(A) = n(A) / n(S)
ComplementP(A′) = 1 − P(A)
Independent eventsP(A ∩ B) = P(A)P(B)
Conditional probabilityP(A|B) = P(A ∩ B)/P(B)
⚠️ Conditional probability mein P(B) ≠ 0 hona chahiye. Independent aur mutually exclusive events same cheez nahi hain.
